## 📊 Documentacion de BD

Para comprender mejor la base de  datos, hemos elaborado los diagramas correspondientes. Estos archivos están alojados de forma segura en Google Drive.

> **¿Qué encontrarás en la carpeta?**

> * 🟦 **Diagrama Relacional:** Esquema lógico que detalla las tablas, claves primarias (PK), claves foráneas (FK) y la cardinalidad.
